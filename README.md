# Challenge Travel & Tours — تشالنج ترافل & تورز

> **Site vitrine officiel de l'agence de voyage et tourisme Challenge Travel & Tours (Alger, Algérie)**  
> *Spécialiste Omra, Visas Arabie Saoudite, Billetterie internationale et Tourisme.*

---

## 🌟 Présentation du Projet

Site web moderne, rapide et responsive conçu avec les technologies web modernes :
- **Architecture :** HTML5 sémantique, CSS3 (Variables, Grid, Flexbox, Glassmorphism), JavaScript ES6+
- **Langue & Typographie :** 100% Arabe avec support RTL complet, polices Google Fonts (*Cairo* & *Amiri*)
- **Fonctionnalités Clés :**
  - Section Hero attractive avec **module interactif de devis et réservation directe** (Omra, Visas, Vols)
  - Intégration WhatsApp directe avec messages préremplis vers `+213 773 496 112`
  - Formulaire de contact fonctionnel relié à l'adresse email de l'agence
  - Vitrine des programmes Omra et offres saisonnières (Ramadan, Rajab, Chaâbane)
  - Galerie interactive et actualités avec fenêtres modales détaillées
  - Configuration de déploiement instantané pour **Vercel** (`vercel.json`) et WordPress (`wordpress-kit`)

---

## 🚀 Déploiement sur Vercel

Ce projet est configuré pour un déploiement en 1 clic sur Vercel :
1. Connectez votre compte GitHub sur [vercel.com](https://vercel.com).
2. Cliquez sur **"Add New..." > "Project"**.
3. Importez le dépôt **`Sidodido/challenge-travel`**.
4. Cliquez sur **Deploy** — Vercel détecte automatiquement la configuration `vercel.json` et déploie le site en quelques secondes !
